# Workfare Pay media

The current background film lives in [`v5/`](./v5/README.md): two complete glass/titanium objects with a controlled, slow 20-second depth cycle. Both themes use the same rigid geometry and a fixed camera. The full silhouette is displayed with `contain`; the video does not crop into an abstract fragment on mobile.

The reproducible Blender source lives in [`design/pay-material/`](../../../design/pay-material/README.md). The films use native 1024 × 768 at 12 fps, with no audio, optical-flow interpolation or generated deformation. Matching WebP posters come from the final decoded first frames. No additional generation credits were used for v5.

The previous [`v4/`](./v4/README.md) files remain temporarily available for already-open application sessions. They are no longer selected by the current interface.

Older bridge media are no longer shipped. Generation masters, render bases, intermediate frames and QA reports remain outside the repository.
