# Workfare Pay · material film v5

Two rigid optical-glass/titanium plates with the original small Workfare mark.
The camera and studio lights stay fixed; the objects follow a slow analytic
cosine translation/rotation cycle. No paid generation, morphing, optical-flow
interpolation, crossfade loop or camera fly-through is used.

Both variants are native **1024 × 768, 12 fps, 240 frames / 20 seconds**, silent
H.264/BT.709 with front-loaded metadata. The 121 unique 3D poses per theme are
rendered in Cycles; the remaining cycle positions are mathematically identical.
Geometry and transforms match exactly between light and dark. Only the real
stationary studio lighting differs.

The WebP posters match each final decoded first frame exactly. Delivery reports
record visible five-second motion, the loop boundary and file sizes. Each film
is approximately 1.3 MB. Source and reproduction instructions are in
[`design/pay-material`](../../../../design/pay-material).
